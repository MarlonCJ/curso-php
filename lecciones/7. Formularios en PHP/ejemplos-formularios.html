Capítulo 1: Ejemplos de formularios HTML

Estos ejemplos usan únicamente HTML. Puedes abrir este archivo en el navegador para probar los controles y leerlo en un editor para estudiar su estructura. Todavía no se procesan, guardan ni validan los datos en un servidor.

1. Formulario sencillo

Cada control que quieras enviar necesita un atributo name. El texto de label se asocia al control mediante los valores iguales de for e id.

Al enviarlo, el navegador agrega el dato a la dirección porque el método es GET. No escribas información privada en este ejemplo.

2. Campos de contacto y texto largo

El tipo email ofrece un control apropiado para una dirección de correo. textarea sirve para mensajes de varias líneas. required solicita que el navegador no deje enviar un campo vacío.


3. Elegir una opción

Los botones de opción permiten seleccionar una opción de un grupo. Comparten el mismo name y cada uno tiene un value distinto. Una lista desplegable es útil cuando hay varias opciones.

¿Cómo prefieres que te contactemos?

4. Seleccionar varias opciones

Las casillas independientes permiten marcar varias opciones. Usa un name para cada dato y un value que identifique cada selección.

¿Qué temas te interesan?

5. Números y fechas con restricciones

Los atributos min, max y step orientan al navegador sobre los valores aceptados. Son ayudas para la experiencia de uso, no una garantía de que los datos sean válidos.

6. ¿Qué hace GET y qué hace POST?

  • GET: envía los datos como parte de la dirección. Es adecuado para búsquedas y filtros que se pueden volver a consultar o compartir.
  • POST: envía los datos en el cuerpo de la solicitud en lugar de agregarlos a la dirección. Se usa habitualmente para enviar datos

POST no cifra los datos ni los hace privados por sí solo; para proteger la transmisión se necesita HTTPS. En ambos métodos, un servidor debe recibir y procesar lo enviado. Este archivo es estático y todavía no incluye ese procesamiento.

Prueba de aprendizaje

  1. Completa el nombre en el primer formulario y envíalo; observa la dirección.
  2. Intenta enviar el formulario de contacto sin completar sus campos.
  3. Prueba una dirección de correo con formato incorrecto.
  4. Selecciona una preferencia y varios temas; observa qué datos aparecen al enviar.
  5. Abre este archivo en un editor y localiza form, label, input y button.
